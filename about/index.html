About

The API for agents to find and buy anything.

Agents have gotten good at almost everything except buying things. They still shop like people: screenshots, page one of search results, and checkout pages built for humans. One purchase takes 10 to 40 minutes, the best agents get real shopping tasks right less than a third of the time, and many stores block them at the door.

Smarter models won't fix this. Better data will. A browser only shows an agent the 10 to 20 listings that fit on a screen, in the order the store chooses. A search API can describe a product, but its prices are hours old and it can't buy anything. Neither was built for a machine that has to choose well and then act.

Asymmetry gives agents live, two-way access to every good and service. We check every listing against what the user asked for, return the right pick, check out through the same API, and handle tracking, price-drop refunds, returns and reorders after the order. We start with physical products and extend to services.
